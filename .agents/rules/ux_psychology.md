# UX Psychology Principles & Cognitive Design Rules

## 1. Smart Defaults & Choice Architecture (Decision Fatigue)
- **Eliminate Blank Forms**: Never present users with empty input fields when sensible presets exist.
- **The Jam Study Heuristic**: More choices create friction (24 choices = 3% conversions; 6 choices = 30% conversions).
- **Default Power**: 70%–90% of users never modify default settings; they interpret defaults as trusted recommendations.
- **Scan & Adjust**: Shift the user workflow from "construct from scratch" to "review and adjust".
- **Pre-select The Winner**: Automatically select the highest-converting or most common option for every picker, frequency, and time window.

## 2. Goal Gradient Effect & Artificial Momentum
- **The Head Start Effect**: People accelerate effort as they approach completion (e.g. car wash loyalty card with 2/10 bonus stamps achieves 2× completion vs a blank 8-stamp card).
- **Never Start at Zero**: 0% progress feels paralyzing; 20% creates instant forward momentum.
- **Credit Prior Action**: Count initial onboarding steps, account creation, or default setup as completed progress.
- **Progress Framing**: Display profile strength, goal completeness, or setup checklists with pre-awarded milestones.

## 3. Reciprocity & Value-First Architecture
- **Deliver Value Before Gating**: Never hold critical insights hostage behind an immediate registration wall.
- **The Reciprocity Trigger**: Providing upfront value creates an unconscious psychological impulse to reciprocate (free samples increase conversions up to 2,000%).
- **Sample & Reveal**: Expose actionable previews, sample workflows, or partial analysis prior to asking for commitment.
- **Frictionless Handoff**: When a user already receives tangible utility, signing up feels like claiming work, not surrendering credentials.

## 4. IKEA Effect & Endowment Effect (Invested Labor)
- **Ownership Through Creation**: Users assign disproportionately higher value to artifacts they have helped configure or build.
- **Customize Before Signup**: Allow users to customize their workspace name, themes, habits, and primary horizons *before* displaying an account barrier.
- **Progressive Investment**: Every configuration choice makes the workspace feel proprietary (e.g. Duolingo lesson completion before account creation).
- **Button Framing**: Use progression verbs like "Continue" or "Keep Building" rather than generic "Sign Up".
- **Loss of Labor**: Exiting should feel like abandoning their own creation, not skipping a website form.

## 5. Loss Aversion & The Cost of Inaction
- **2× Asymmetry**: The psychological pain of losing an asset is twice as intense as the pleasure of gaining the equivalent asset.
- **Loss-Framed Urgency**: Framing an action around avoiding a loss is significantly more motivating than promising future benefits.
- **Concrete Threat Over Abstract Pitch**: Highlight real artifacts, active streaks, and expiring buffers by name rather than generic feature lists.
- **Choice Architecture for Dismissal**: Frame rejection choices around deliberate risk (e.g. "I'll risk losing my streak" vs "Maybe later").
- **Cost of Inaction**: Clearly visualize what degrades, stalls, or expires if the user fails to act.

## 6. Contrast Effect & Numerical Anchoring
- **Relative Valuation**: The human brain evaluates costs and metrics relatively, never in absolute isolation.
- **The Anchor Ruler**: The first number or metric a user encounters sets the baseline ruler against which all subsequent values are compared.
- **Contextual Pricing**: A \$50 add-on appears trivial when anchored against a \$1,900 laptop (2.6%), but exorbitant when presented in isolation.
- **Strategic High Anchors**: Position high-value benchmark tiers or extreme reference points first to make standard recommendations feel balanced and accessible.
- **Never Show Cost Alone**: Always pair commitments with a larger benchmark or previous return on investment.

## 7. Core Operating Summary
1. Defaults are interpreted as recommendations.
2. Artificial progress sparks genuine psychological momentum.
3. Upfront gifts create reciprocal commitment.
4. Invested labor manufactures personal attachment.
5. Fear of loss drives action faster than hope of gain.
6. Anchors dictate value perception.
